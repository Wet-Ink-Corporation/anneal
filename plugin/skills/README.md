# Skills

One directory per skill, each with a `SKILL.md`. Release 2 brings the first three, all model-invoked: `grill` (question a new or vague request until the requirements are confirmed), `spec` (write the spec) and `plan` (split the spec into tasks and get the plan approved). `diagnose` (reproduce a failure red, then find its root cause) followed. Release 3 adds `build` (build an approved task test-first, with `references/constraints.md` for check placement and `references/tdd.md` for the loop) and `verify` (prove work done with a fresh test run and a doubt pass before claiming it). Release 4 adds `ship` (review, merge, migration and rollout, each GO or NO-GO with a rollback plan, with `references/migrate.md` for expand, migrate, contract and its wave tracker and `references/release.md` for rollout bands and error budgets).

`handoff` is the first user-invoked skill (`disable-model-invocation: true`, run as `/anneal:handoff`): at a phase boundary or when the context monitor warns, it chooses continue, clear, hand off, a subagent or compact, and puts what must survive in `.continue-here` (see `docs/handoff.md`).

`orchestrate` is user-invoked too (`/anneal:orchestrate`, about 15 times the tokens of one session): it fans out over a plan's ready tickets only when `anneal orchestrate fan-out` finds 3 or more independent ones, gives each a brief and a fresh verifier, and parks one-way calls in weigh-in (`anneal orchestrate park`, after Clef D2) or rules on them (`anneal orchestrate rule`); see `docs/orchestrate.md`.

The learn-phase skills are user-invoked too (#43): `/anneal:correct` fixes a mistake at the highest level that holds (architecture, types, a lint, a test, docs last) and records each rule under `## Rules` with its enforcer, which `anneal lint rules` checks (`docs/skill-rules.md`); `/anneal:write-skill` writes a skill test-first, from a case that fails with no guidance, through Tiers 0 to 3 (`references/tiers.md`, `evals/README.md`); `/anneal:calibrate` runs `anneal calibrate`, explains each point's verdict, shows the proposed thresholds as a diff and writes them only with `anneal calibrate --apply` after the human's yes (`docs/calibrate.md`). Like `handoff` and `orchestrate`, they have no routing fixture or uplift suite: the model never routes to them.
