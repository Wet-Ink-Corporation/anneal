# Skills

One directory per skill, each with a `SKILL.md`. Release 2 brings the first three, all model-invoked: `grill` (question a new or vague request until the requirements are confirmed), `spec` (write the spec) and `plan` (split the spec into tasks and get the plan approved). `diagnose` (reproduce a failure red, then find its root cause) followed. Release 3 adds `build` (build an approved task test-first, with `references/constraints.md` for check placement and `references/tdd.md` for the loop).
